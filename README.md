Flowline is a modern task management web application developed as an internship project to help users organize and track their daily tasks efficiently. The application provides a secure authentication system that allows users to register and log in before accessing their personalized workspace. Users can create, update, delete, and manage tasks using an intuitive Kanban board with To Do, In Progress, and Done columns. The application also supports real-time synchronization across browser tabs, task search and filtering, priority labels, and a fully responsive design that works seamlessly on desktops, tablets, and mobile devices. Built using HTML5, CSS3, JavaScript, and browser localStorage, Flowline is structured to simulate a full-stack architecture and can be easily extended with technologies such as Node.js, Express.js, and MongoDB/PostgreSQL for production use. This project demonstrates essential web development concepts, including CRUD operations, authentication, state management, responsive UI design, and scalable application architecture.
